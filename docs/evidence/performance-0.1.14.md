# QuickPeek 0.1.14 性能实测

测试版本为 `154bdaf`，使用已安装的 Windows x64 Release 程序。机器为 Windows 11 build 26300、i5-13600KF、RTX 4060 Ti、约 32 GB 内存。各个前台测试串行执行。新进程启动保留系统磁盘缓存，WebView2 测试使用新的用户数据目录。结果仅代表这台机器。

## 资源管理器空格预览

在同一个资源管理器窗口交替选择两张颜色不同的 PNG，按空格，验证前台窗口标题和图像中心像素，然后再按空格关闭。30 次中 30 次在 2.2 秒期限内显示了正确内容。按键到内容的中位数为 298 ms，P95 为 587 ms，最小和最大值分别为 147、594 ms。P95 取最近秩。

## 默认预览与翻页

每项直接启动新进程三次。GPUI 文本按标题栏下正文像素判定，图片按采样区域的明暗像素判定。PDF 和合成 MP4 按指定内容颜色判定。时间包含屏幕采样，工作集在首屏之后采样，仅计预览主进程。

## 空闲资源

所有测试预览关闭后，QuickPeek 剩余托盘和一个预热进程。分别采样这两个进程约 8 秒。

| 进程 | 工作集（MiB） | 私有提交（MiB） | 区间 CPU 时间（秒） |
|---|---:|---:|---:|
| tray | 29.9 | 4 | 0.015625 |
| standby | 48.7 | 57.6 | 0 |

本轮未覆盖无独立显卡机器、网络文件、系统冷启动、播放帧率或长时间内存增长。三次重复的项目只用于报告本机典型耗时。
