# QuickPeek 0.1.16 文档冷启动对照

Windows 同机交错测试。基线为已发布的 0.1.15。同一文件、同一套探针，两个版本各启动十个独立的进程，每次分配全新的 WebView2 用户数据目录，文件系统缓存未清空。首屏就绪指正确文档完成表格或沙箱页面渲染，并等待两个动画帧。准备耗时从启动计到预览 HTML 写完。十次样本的 P95 会等于最大值，表内列中位数和最慢值。

| 文件 | 旧版就绪中位数 / 最慢（ms） | 新版就绪中位数 / 最慢（ms） | 旧版 / 新版准备中位数（ms） |
|---|---:|---:|---:|
| 10mb.html | 1096.5 / 1180 | 1034 / 1102 | 137 / 139 |
| large.xlsx | 994.5 / 1093 | 1035 / 1108 | 429 / 456 |
| 150k.xlsx | 1202 / 1304 | 1079 / 1134 | 1084.5 / 956 |

HTML 校验完整源码和末页。表格使用 10 列、5 万行和 15 万行的 XLSX，核对总行数、每页 100 行，以及首行、末行各十个单元格与原始 OOXML 相符。15 万行样本重复使用 5 万行样本的文本，行号和单元格引用连续。

## 复用已有 WebView2 配置的冷启动

使用两版正式打包目录。给各版本分配独立测试配置，用相同文件预先初始化配置；每个计时样本前确认该配置的 WebView2 进程均已退出。预备轮不计时。两版各运行十轮，继续校验 HTML 末页及 Excel 真实单元格。

| 文件 | 旧版中位数 / 最慢（ms） | 新版中位数 / 最慢（ms） |
|---|---:|---:|
| large.xlsx | 1105 / 1189 | 1125 / 1237 |
| 10mb.html | 1211.5 / 1303 | 1156.5 / 1273 |

## 资源管理器空格预览

按 PNG、TXT、PNG、PS1 的顺序循环。每次确认选中的文件内容已显示，再关闭预览并确认焦点回到原来的资源管理器窗口。两个版本依次测量，各 100 次。

| 版本 | 成功 | 中位数 / P95 / 最慢（ms） |
|---|---:|---:|
| 0.1.15 | 100/100 | 145.5 / 168 / 199 |
| 0.1.16 | 100/100 | 142 / 163 / 198 |

21 项 Rust 测试和 release Clippy 通过。额外在真实 WebView2 检查 HTML 包装层、样式、来回翻页、沙箱和源码切换，以及阅读器原有的搜索和键盘操作。结果仅代表这台机器，未测试重启后首次磁盘读取和无独显设备。
