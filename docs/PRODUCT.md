# QuickPeek 首版约定

目标：Windows 11 x64，纯 Rust，windows-reactor / WinUI 3，解压即用。

首版：图片、文本、视频、Markdown 渲染、PDF、代码高亮、JSON 格式化。
后台托盘驻留；资源管理器选中文件按 Space 打开；Space / Esc 关闭；左右键切换；Enter 外部打开。PDF 内 Space、方向键和 Enter 保留阅读器行为，Esc 关闭预览。
预留版本化插件协议与进程隔离，不在首版自动加载第三方代码。

## 视觉

参考用户提供的两张 2026-09-22 原型：雾白半透明材质、克制的蓝色、圆角、细分隔线、内容占主体。
结构：左上角项目图标和文件名，右上角图钉紧邻并对齐系统窗口按钮；不显示“更多”、通用常驻工具栏或底部快捷键提示。PDF 保留阅读器自身的翻页、缩放和搜索工具。
阅读类文本按 Ctrl+F 打开搜索，Esc 优先收起搜索，搜索框默认隐藏。
打开时居中，默认不固定置顶；图钉可切换置顶，蓝色表示已开启。
Windows 标题栏按钮，不使用 macOS 红黄绿按钮。随系统主题调整背景和文字。
交互：窗口自然出现；信息面板按需展开；媒体控件只承担播放与定位功能。

## 工程边界

文件识别和解析与 UI 分离。读取有上限，耗时解析放到后台，切换后过期结果不得覆盖当前文件。
JSON 仅格式化显示，不写回；保留数字精度与键顺序。
Markdown 不执行 HTML / JavaScript，也不自动请求远程图片。
视频使用 Windows Media Foundation，格式能力受系统解码器影响。
PDF 使用 WinUI WebView2 原生阅读器，支持连续滚动、文字选择和 Ctrl+滚轮缩放；依赖系统 WebView2 Runtime，无需另行分发 PDFium。图片使用原生滚动容器和 Ctrl+滚轮缩放。
便携包携带 Windows App SDK 运行时，不能只分发一个 exe。
